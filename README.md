# Автоматизированный поиск первоисточника новостей

Система для анализа новостных статей и определения наиболее вероятного первоисточника.

## 🔧 Функциональность

- Сбор статей по списку URL
- Анализ надежности источника (рейтинг 1-5)
- Анализ уникальности текста (эвристики или ML)
- Определение первоисточника по дате, рейтингу и уникальности
- Веб-интерфейс на Streamlit
