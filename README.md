## Описание проекта
Программа представляет собой автоматизированную OSINT-систему верификации новостного контента и определения его первоисточника. 

Система осуществляет сквозной мониторинг по ключевым запросам через интеграцию с поисковыми RSS-движками (Google News и Яндекс Поиск), производит автоматическую дешифровку URL с помощью Selenium, извлекает текстовые корпуса и метаданные статей.

Верификация и классификация источников строятся на основе двух подходов:
1. **Структурно-технический анализ домена (Эвристический):** Сбор признаков веб-ресурса (наличие HTTPS, страниц контактов, правовой информации, упоминания редакции, социальный граф) с вычислением рейтинга надежности (1–5).
2. **Семантический анализ текста (ML-подход):** Использование легковесной языковой модели эмбеддингов для оценки косинусного сходства текстовых корпусов и вычисления точной метрики уникальности.

На основе интеграции временных и текстовых метрик агрегатор выстраивает цепочку заимствований и математически точно определяет **первоисточник** новостного инфоповода. Результаты анализа кэшируются в локальную базу данных SQLite и могут быть экспортированы в структурированный JSON-отчет.

## Структура репозитория

* `modules/` — функциональные модули системы:
  * `modules/collector.py` — движок загрузки, очистки контента и извлечения дат публикаций (`newspaper3k`, `trafilatura`).
  * `modules/news_search.py` — компонент агрегации сырых ссылок из RSS-лент Google/Яндекс и их дешифровки через Selenium Headless.
  * `modules/analyzer_site.py` — модуль OSINT-анализа признаков надежности домена.
  * `modules/analyzer_text.py` — семантический анализатор уникальности текстов на базе машинного обучения.
  * `modules/aggregator.py` — математический алгоритм сопоставления метрик и выявления первоисточника.
  * `modules/database.py` — ORM-слой (SQLAlchemy) для взаимодействия с базой данных.
* `ui/` — графический интерфейс пользователя:
  * `ui/streamlit_app.py` — веб-приложение на фреймворке Streamlit с интерактивными вкладками, графиками и экспортом отчетов.
* `data/` — локальное хранилище данных:
  * `data/news.db` — рабочая база данных SQLite со структурированными логами расследований.
* `main.py` — консольная (CLI) версия программы для быстрого проведения OSINT-экспертизы через терминал.
* `check_db.py` — утилита отладки для красивого вывода содержимого базы данных в консоль с помощью `pandas`.
* `config.py` — глобальный конфигурационный файл системы (таймауты, User-Agent, пути к БД).
* `requirements.txt` — манифест зависимостей проекта с фиксированными версиями библиотек.

## Инструкция по запуску

1. Клонирование репозитория
Разверните проект в локальную папку на вашем компьютере:
git clone https://github.com/dariashulga/my-coursework
cd repo

2. Установка зависимостей
Рекомендуется использовать виртуальное окружение (venv). Для установки всех необходимых библиотек 
(включая ML-компоненты, парсеры и движок базы данных) выполните команду:
pip install -r requirements.txt

3. Запуск графического веб-интерфейса (Streamlit)
Для работы в интерактивном режиме через веб-браузер запустите команду:
streamlit run ui/streamlit_app.py

4. Запуск консольной версии (Альтернативный вариант)
Для проведения экспресс-анализа темы напрямую через терминал выполните:
python main.py

5. Просмотр результатов в базе данных
Для быстрой проверки записей в таблице результатов выполните отладочный скрипт:
python check_db.py
